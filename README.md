# website-2026

Nieuwe website voor [jeau.st](https://jeau.st). Astro 7 met Tailwind v4, gehost op Cloudflare Workers.

## Aan de slag

```
npm install
npm run dev
```

## Commando's

| Commando | Wat het doet |
| --- | --- |
| `npm run dev` | Dev server op http://localhost:4321 |
| `npm run build` | Bouwt de site naar `dist/` |
| `npm run typecheck` | Astro- en TypeScript-diagnostiek |
| `npm run preview` | Bouwt en serveert via de Workers-runtime |
| `npm run deploy` | Bouwt en deployt naar Cloudflare Workers |

Projectafspraken staan in [CLAUDE.md](CLAUDE.md).
